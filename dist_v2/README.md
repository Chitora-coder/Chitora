# AI Assistant - MCQ Quiz Version 2

## Quick Start

1. **Run**: Double-click `AI_Assistant_MCQ.exe`
2. **Use**: 
   - Display an MCQ C programming question on screen
   - Press **Alt + S**
   - Loading cursor appears
   - Answer (A, B, C, or D) appears in bottom-left corner for 2 seconds
3. **Stop**: End via Task Manager

## Features
- Specialized for Multiple Choice Questions
- Returns only the letter (A, B, C, or D)
- Answer appears in bottom-left corner
- Auto-disappears after 2 seconds
- Loading cursor during processing

## Hotkey
**Alt + S**
